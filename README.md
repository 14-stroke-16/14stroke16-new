# 14stroke16

Community diary — fashion, art, culture.

## Stack

Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS · Contentful · Vercel

See [ARCHITECTURE.md](./ARCHITECTURE.md) for structure and conventions.

## Local development

```bash
npm install
npm run dev
```

Requires a local `.env.local` with the project's Contentful credentials (kept out of version control).

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run start` — serve the production build
- `npm run lint` — ESLint
- `npm run format` — Prettier
